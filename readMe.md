BTC price prediction Tool

Use pure indicators based from K-lines to build the model for predictiing BTC price in the next 12 hours.

Output:
1. Direction
2. Range
3. Confidence

Only trading when 
1. range is > 2%
2. cummulative confidence >= 75%

Exit:
1. direction reverses | range changes
2. cummulative confidence starts to fade < 50% (usually quickly drop below 35%)
